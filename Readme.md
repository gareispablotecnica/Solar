# SOLAR

Aplicación móvil desarrollada con **React Native y Expo**, orientada a la exploración visual del **Sistema Solar**.

El proyecto presenta diferentes planetas mediante imágenes y fondos espaciales, con una interfaz pensada para brindar una experiencia visual e interactiva.

##  Tecnologías utilizadas

* **React Native**
* **Expo**
* **JavaScript**
* **VS Code**
* **Git / GitHub**

##  Contenido

La aplicación utiliza recursos gráficos relacionados con el espacio y los planetas del Sistema Solar.

Entre los recursos se encuentran:

* Fondos espaciales.
* Imágenes de los planetas.
* Animaciones en formato GIF.
* Pantallas para la navegación de la aplicación.

Los planetas están organizados dentro de:

```text
src/Media/Planetas/
```

##  Recursos multimedia

Los fondos utilizados por la aplicación se encuentran en:

```text
src/Media/Fondo/
```

Mientras que las imágenes correspondientes a los planetas se encuentran en:

```text
src/Media/Planetas/
```

##  Instalación

Para ejecutar el proyecto localmente, primero se deben instalar las dependencias:

```bash
npm install
```

Luego iniciar el proyecto con Expo:

```bash
npx expo start
```

Desde el menú de Expo se puede ejecutar la aplicación utilizando:

*  Expo Go
*  Android
*  iOS
*  Navegador web


##  Objetivo del proyecto

El objetivo de **SOLAR** es desarrollar una aplicación móvil interactiva relacionada con el Sistema Solar, utilizando React Native para construir la interfaz y Expo como entorno de desarrollo.

El proyecto busca combinar **programación, diseño visual y recursos multimedia** para presentar información relacionada con los planetas de una manera atractiva y sencilla.
